# Experiments

Each subdirectory contains materials for one experiment.

- [Prompt sensitivity](prompt_sensitivity/): 300 sampled interactions, three prompt profiles, and 900 scores.
- [LLM backend sensitivity](model_sensitivity/): 300 identical P0 text pairs scored by DeepSeek, GLM, and Doubao, with dimensional ratings and six reference comparisons.
- [Human validation](human_validation/): results from the existing public repository, supplemented with sampled text pairs. Existing ratings and summary statistics are unchanged.

Historical exploratory runs are not included. Additional experiments can be added in separate subdirectories after their settings and results are checked against the manuscript.
