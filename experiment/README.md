# Experiments

Each subdirectory contains materials for one experiment.

- [Prompt sensitivity](prompt_sensitivity/): 300 sampled interactions, three prompt profiles, and 900 scores.
- [Human validation](human_validation/): the three files from the existing public human-validation repository, preserved byte for byte.

Historical exploratory runs are not included. Additional experiments can be added in separate subdirectories after their settings and results are checked against the manuscript.
